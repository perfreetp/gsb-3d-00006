# 自动化立体仓库 3D 仿真系统

基于 **Vue 3 + TypeScript + Vite + Three.js** 的可直接运行的 3D 自动化立体仓库（AS/RS）仿真。

## 运行

```bash
npm install
npm run dev        # 开发模式，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

## 功能

- **场景**：A/B 双侧货架（6 层 × 16 列，共 192 个货位）、托盘货物、巷道堆垛机（门架、载货台、伸缩货叉、行走/起升机构）、入库/出库滚筒输送带、出入库口。
- **随机任务**：随机生成入库任务（货物随输送带抵达入库口）和出库任务（从随机占用货位取货送至出库口）；也可手动下发任务。
- **真实状态逻辑驱动**：堆垛机由显式状态机驱动（驶向取货位 → 伸叉 → 微抬取货 → 收叉 → 驶向目标位 → 伸叉 → 微降放货 → 收叉），行走 Z、起升 Y、货叉 X 三个轴按速度逐帧积分逼近目标，没有任何固定动画时间线。输送带速度、辊筒旋转、占用地图均由同一仿真状态驱动。
- **任务与状态展示**：当前任务、阶段、目标货位、载货托盘号、堆垛机各轴实时位置/速度、出入库口状态、待执行队列、运行日志和统计指标。
- **交互**：
  - 点击任意货架货位，高亮并显示该货位占用情况与货物信息（侧栏占用图同步）；
  - 暂停/继续仿真（暂停时仿真时间冻结）；
  - 0.25×–6× 多档 + 滑块连续调速，作用于全部设备的逻辑运动；
  - 鼠标左键旋转、右键平移、滚轮缩放，可复位视角。

## 代码结构

- `src/sim/config.ts`：仓库几何与设备速度常量
- `src/sim/scene.ts`：地面、货架、输送带、灯光等静态场景
- `src/sim/crane.ts`：堆垛机模型（含叉齿节点）
- `src/sim/materials.ts` / `labels.ts`：材质、货物类型、文字标签
- `src/sim/simulation.ts`：仿真核心——任务调度、堆垛机状态机、输送带、占用模型、拾取、快照
- `src/components/*`：控制面板、任务状态、货位占用图、日志等 UI
